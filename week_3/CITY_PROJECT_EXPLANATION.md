## 3. City Validation & Highlights Parser (`parse_city_validity`)

```python
def parse_city_validity(raw_reply: str, user_text: str):
```
- Function that takes the raw text generated by the LLM along with the original user input, and returns four pieces of information:
  1. `clean_reply`: The descriptive text for display & TTS (with metadata tags removed).
  2. `is_valid`: Boolean indicating whether the input is a valid city.
  3. `city_name`: The recognized city name.
  4. `highlights`: A dictionary containing `{"building": ..., "food": ..., "culture": ...}`.

```python
    pattern = r"\[VALID_CITY:\s*([^\]]+)\]"
    match = re.search(pattern, raw_reply, re.IGNORECASE)
    is_valid = False
    city_name = user_text.strip()
    highlights = {"building": "", "food": "", "culture": ""}
```
- Matches anything inside `[VALID_CITY: ...]`.

```python
    if match:
        content = match.group(1).strip()
        parts = [p.strip() for p in content.split("|")]
        status = parts[0].upper()
        if "YES" in status:
            is_valid = True
            if len(parts) > 1 and parts[1]:
                city_name = parts[1]
            for part in parts[2:]:
                if ":" in part:
                    k, v = part.split(":", 1)
                    k_clean = k.strip().lower()
                    if "building" in k_clean or "landmark" in k_clean:
                        highlights["building"] = v.strip()
                    elif "food" in k_clean or "culinary" in k_clean or "dish" in k_clean:
                        highlights["food"] = v.strip()
                    elif "culture" in k_clean or "tradition" in k_clean:
                        highlights["culture"] = v.strip()
        clean_reply = re.sub(pattern, "", raw_reply).strip()
```
- Splits the metadata tag by pipe `|` and parses any named attributes (`Building: ...`, `Food: ...`, `Culture: ...`) into the `highlights` dictionary.
- Cleans and strips the tag from the text before returning.

```python
    else:
        clean_reply = raw_reply.strip()
        negative_signals = [
            "not a valid city",
            "not a real city",
            "not recognized as a city",
            "only specialize in real cities",
            "please name a valid city",
            "please provide a valid city",
        ]
        if any(sig in clean_reply.lower() for sig in negative_signals):
            is_valid = False
            city_name = ""
        else:
            is_valid = True
            city_name = user_text.strip()

    return clean_reply, is_valid, city_name, highlights
```
- Fallback logic if the structured tag was not produced, ensuring robust operation.
- Returns the tuple `(clean_reply, is_valid, city_name)`.

## 4. Chatbot History Normalization & Input Handler

```python
def _normalize_history(chatbot):
    if not chatbot:
        return []
    normalized = []
    for item in chatbot:
        if isinstance(item, dict) and "role" in item and "content" in item:
            normalized.append(item)
        elif isinstance(item, (list, tuple)) and len(item) == 2:
            if item[0] is not None:
                normalized.append({"role": "user", "content": str(item[0])})
            if item[1] is not None:
                normalized.append({"role": "assistant", "content": str(item[1])})
    return normalized
```
- **Ensures Gradio `messages` compliance**: Modern Gradio (5+ and 6+) strictly requires that each entry in `gr.Chatbot` be a dictionary with `'role'` and `'content'` keys (or a `ChatMessage` object). This helper converts any legacy tuples or raw data into conforming message dicts: `[{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]`.

```python
def put_message_in_chatbot(message, chatbot):
    if not message or not message.strip():
        return "", chatbot
    history = _normalize_history(chatbot)
    history.append({"role": "user", "content": message.strip()})
    return "", history
```
- Runs immediately when the user presses Enter:
  1. Ignores whitespace-only submissions.
  2. Appends `{"role": "user", "content": message.strip()}` to the normalized history.
  3. Returns `""` (which resets the `gr.Textbox` to blank) and the new `history` list (displaying the user's message instantly in the chat window).

## 5. Orchestration Logic (`chat`)

```python
def chat(chatbot):
```
- Receives the updated `chatbot` conversation history, calls all 3 endpoints sequentially, and returns `[chatbot, audio_path, image_obj]`.

### (a) Guard Checks

```python
    history = _normalize_history(chatbot)
    if not history:
        return history, None, None

    # Retrieve user query from the most recent user message
    user_message = ""
    for msg in reversed(history):
        if msg.get("role") == "user":
            user_message = msg.get("content", "")
            break

    if not user_message:
        return history, None, None
```
- Extracts the text entered by the user from the most recent `user` turn in the history.

```python
    if "YOUR_NGROK_URL" in NGROK_URL:
        err_msg = (
            "⚠️ NGROK_URL is not set! Please edit `multi_modal_client_city_project.py` "
            "and set NGROK_URL to your public Colab ngrok URL."
        )
        history.append({"role": "assistant", "content": err_msg})
        return history, None, None
```
- Prevents confusing tracebacks if the user launches the script without configuring the ngrok URL, appending a helpful assistant alert into the chat.

### (b) Step 1: Chat Completion (`/chat`)

```python
    try:
        chat_payload = {
            "messages": [
                {"role": "system", "content": SYSTEM_PROMPT},

            "temperature": 0.7,

        res = requests.post(CHAT_ENDPOINT, json=chat_payload, timeout=60)

```
- Packages the system prompt and user inquiry into the chat payload.
- Sends an HTTP POST to `CHAT_ENDPOINT`.
- Extracts the text response.

```python
    clean_reply, is_valid, city_name = parse_city_validity(raw_reply, user_message)

    # Append assistant response
    history.append({"role": "assistant", "content": clean_reply})
```
- Cleans the response, removes technical metadata tags, and appends the assistant's message as a compliant dictionary to the conversation history.

---

### (c) Step 2: Text-to-Speech (`/tts`)

```python
    audio_path = None
    try:
        tts_payload = {"text": clean_reply}
        tts_res = requests.post(TTS_ENDPOINT, json=tts_payload, timeout=60)
        tts_res.raise_for_status()
        audio_path = "city_voice.wav"
        with open(audio_path, "wb") as f:
            f.write(tts_res.content)
    except Exception as e:
        print(f"[!] TTS generation failed: {e}")
        audio_path = None
```
- Sends the synthesized text to `/tts`.
- Saves the returned 16-bit PCM WAV bytes to disk as `city_voice.wav`.
- If an error occurs, it prints the error and sets `audio_path = None` without crashing the app.

### (d) Step 3: Style-Aware Image Generation (`/generate-image`)

```python
    image_obj = None
    if is_valid and city_name:
        try:
            if image_style == "Pop Art":
                image_prompt = (
                    f"Vibrant pop art painting of {city_name}, iconic landmarks and skyline, "
                    f"bold contrasting colors, Roy Lichtenstein and Andy Warhol style, "
                    f"silkscreen print aesthetic, halftone dots, sharp outlines, masterpiece"
                )
            elif image_style == "Building, Food & Culture":
                bldg = highlights.get("building") or "iconic historic landmark and architectural monument"
                food = highlights.get("food") or "traditional authentic local food dishes"
                cult = highlights.get("culture") or "vibrant cultural traditions, festive street life"
                image_prompt = (
                    f"A detailed travel collage celebrating {city_name}: featuring {bldg} in the skyline, "
                    f"an appetizing plate of {food} in the foreground, and elements of {cult}, "
                    f"harmonious composition, vibrant colors, highly detailed, 8k resolution, cinematic lighting, masterpiece"
                )
            else:  # "Regular Photo"
                image_prompt = (
                    f"A stunning realistic photo of {city_name}, iconic landmarks and cityscape, "
                    f"high resolution 8k, natural lighting, beautiful architectural photography, "
                    f"photorealistic, sharp details, National Geographic style"
                )
            print(f"[*] Generating '{image_style}' image with prompt: \"{image_prompt}\"")
            img_payload = {
                "prompt": image_prompt,
                "text": image_prompt,
                "num_inference_steps": 30,
                "guidance_scale": 7.5,
            }
            img_res = requests.post(IMAGE_ENDPOINT, json=img_payload, timeout=120)
            img_res.raise_for_status()
            image_obj = Image.open(io.BytesIO(img_res.content))
            image_obj.save("city_image.png")
        except Exception as e:
            print(f"[!] Image generation failed: {e}")
            image_obj = None
    else:
        print(f"[*] '{user_message}' is not a valid city. Skipping image generation.")

    return history, audio_path, image_obj
```
- **Conditional generation & 3-way Style switching**:
  - **"Regular Photo"**: Generates an architectural landscape photograph in sharp focus with natural daylight.
  - **"Pop Art"**: Generates a Roy Lichtenstein / Andy Warhol graphic print with bold lines and halftone dots.
  - **"Building, Food & Culture"**: Uses the LLM-extracted `highlights` dictionary to compose a travel montage featuring the city's signature **building** on the skyline, authentic local **food** in the foreground, and traditional **cultural** motifs.
- If the city is invalid (e.g. `banana`, `asdfgh`), `image_obj` remains `None`.
- Returns `[history, audio_path, image_obj]` to update the Gradio interface simultaneously.

```python

            label="Chat with our AI Assistant:",
            placeholder="Enter a city name (e.g. Tokyo, Paris, Rome, New York)...",
        )
    with gr.Row():
        image_style = gr.Radio(
            label="Image Style",
            choices=["Regular Photo", "Pop Art", "Building, Food & Culture"],
            value="Regular Photo",
            info="Choose how you want the city to be visualized",
        )
```
- Third and Fourth rows:
  - Text input row where the user types the city name.
  - Image style radio selector offering three choices: `"Regular Photo"`, `"Pop Art"`, and `"Building, Food & Culture"`.

```python
    message.submit(
        put_message_in_chatbot,
        inputs=[message, chatbot],
        outputs=[message, chatbot],
    ).then(
        chat,
        inputs=[chatbot, image_style],
        outputs=[chatbot, audio_output, image_output],
    )
```
- **The Chained Event Pipeline**:
  1. `message.submit(...)`: Fires when the user presses Enter in the textbox.
     - Calls `put_message_in_chatbot`.
     - Inputs: `message` text and current `chatbot` history.
     - Outputs: Clears `message` and updates `chatbot` to display the user's text immediately.
  2. `.then(...)`: Triggers immediately after `put_message_in_chatbot` finishes.
     - Calls `chat`.
     - Inputs: Current `chatbot` history and the selected `image_style`.
     - Outputs: Updates `chatbot` with the AI's answer, feeds the audio file to `audio_output`, and renders the generated city image in `image_output`.
